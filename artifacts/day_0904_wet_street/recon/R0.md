## 2. 冻结件事实(`kernels/g14_3_direct_gi.rx`,316 行)

- 签名:`(tlas, t: ThreadCtx<2>, tris, mats, quads, points, params, out_color, out_depth)`。
- 内容模型:逐三角**均值反照率** `mats[mb..mb+3]` + emission `mats[mb+3..mb+6]`,
  8 f32/tri;`tris` 9 f32/tri 世界空间三角汤;`points` 8 f32/point(pos 3 +
  intensity 3)。**无法线贴图、无粗糙度、无 GGX** —— 湿面高光须由 fork 自带。
- 已有 `while` 七处(主射线 / quad 4×4 双层 / 两条阴影 / point 灯),全在
  `if px < width && py < height` 一个 `if` 内。
- 输出:`out_color = hit_f·(emission + albedo·inv_pi·direct)`;
  `out_depth = hit_f·z_hit + (1−hit_f)`,深度取 `params[25..33)` = vp 行 0/1
  (即 clip.x/clip.y,**非** ZO NDC —— 头注与代码不一致,以代码为准)。

## 3. 参数槽位裁决:`params[49..56)`

冻结件头注登记 `[42..48)=reserved(恒 0)`,**但该段不可用**。`g14_3_lane_body.rs`

g35 车道走**基线路** `pack_frame_params`(smooth_nrm=false / ggx=false /
gi2=false),故 `[42..56)` 实测恒 0。但 `[42]` 有 env 驱动写入面 ⇒ 撞位风险真实。

**裁决:湿街段取 `[49..56)` 共 7 槽**(全段无 env 驱动写入,`PARAMS_LEN = 56`


(撞位 fail-closed 自证)⇒ `g14_3_lane_body.rs` **0-byte 不触**。

## 5. 湿面语义(host/device 公式面逐字同源)

host 金标准 = `src/rurix-render/src/world/wet_ground.rs`(**已落盘,20 单测绿**)。

1. 地面带门 `band = smoothstep(1 − |hy − ground_y| / ground_half)`
2. 朝上门 `up = smoothstep((ny − 0.55) / 0.35)`;`wet = wet_on · band · up · hit_f`
3. 积水掩码:0.8 m 格距双线性 value noise,格点 `hash = fract(sin(a·0.3183 +
   b·0.7213)·4096)`;`pud = smoothstep((nv − (1 − puddle_amount)) / 0.18) · wet`
4. 湿反照率 `albedo · lerp(1, wet_dark, wet) · (1 − 0.35·pud)`;
   `roughness = lerp(1, wet_rough, wet) · (1 − 0.6·pud)` ⇒ 逐点灯 GGX D·V +
   Schlick F 加性高光(F0 = 0.03,公式取 `g31_realism.rx` L920-934 逐字)
5. 镜面反射:单条最近命中射线取命中三角 **emission**(路灯 / 店招 / 彩灯串 =
   夜街可反射内容),权 `= Fresnel · wet · wet_spec · (0.35 + 0.65·pud)`

### 5.1 超集性质(门的最强 0-语义漂移证据)

`wet_dark = 1.0 ∧ puddle_amount = 0.0 ∧ wet_spec = 0.0` 时:

```
dark_f   = 1.0 + (1.0−1.0)·(1−wet) = 1.0        恰(0.0·有限 = 0.0)
pud      = smoothstep((nv − 1.0)/0.18)·wet = 0.0 恰(nv ∈ [0,1) ⇒ 参量恒 < 0)
pud_dark = 1 − 0.35·0.0 = 1.0                    恰
spec、refl 各乘 wet_spec = 0.0                   恰(+0.0 对非负色值恒等)
```

⇒ fork 输出与冻结件**逐位相同**。即 fork 是冻结件的**纯超集**,可作独立门 fact。
