## 1. ReSTIR device kernel 兑现语义（M-a）

1. **kernel 面（单 kernel，逐 trial 单 invocation）**：`kernels/g28_restir.rx`——host `gi/restir_reservoir.rs::estimate_ris` 的逐字同源 device 兑现。输入 = ①灯表（`fixture_lights(64)` 由 host 单源生成一次并以原字节上传，pos[3]+intensity 平铺 f32——device 不重生成，`cos/sin/TAU` 超越函数只在 host 出现一次，双端消费同一 f32 位型，RFC-0044 §1.1 域前提同律）②着色点常量（params：pos [0,0,0] / normal [0,1,0]，`variance_experiment` 字面）③随机带双 SSBO + 逐 trial offset 表（§1.2）④params。每 invocation 承载一个 trial：`Reservoir::empty()` 起，M=16 候选顺序 WRS 链——`cand = 候选带[t][j]`；`phat = target_phat` 逐字复算（`d = light.pos − sp.pos`、`dist2 = dot(d,d).max(1e-6)`、`dist = sqrt(dist2)`、`ndotl = (dot(n,d)/dist).max(0.0)`、`phat = intensity·ndotl/dist2`——乘除序逐字）；`w = phat·64`（f32→f64 提升点 host 字面 `f64::from(phat)·n as f64`，精度承载见 §1.3）；update 逐字：`w_sum += w; m += 1; if w_sum > 0 && u < w/w_sum { y = cand; phat_y = phat }`（u 取自判定带下一位；**w_sum ≤ 0 时 && 短路不消费**）；链毕 `unbiased_weight` 逐字（y 空 / phat_y ≤ 0 / m = 0 ⇒ W = 0，否则 `W = w_sum/(phat_y·m)`）；`estimate = phat_y·W`——**禁代数化简**（est 改写为 `w_sum/m` 同值不同舍入，禁）。输出 = 逐 trial {estimate, y, 判定带消费计数, phat_y, w_sum}（对拍承重面 = estimate；y/消费计数为整数锚，phat_y/w_sum 为诊断锚随行入 evidence）。
2. **随机流单源纪律（钉死方案）**：PCG32 u64 状态面整体留 host（G7.4「输入是输入」先例；`Pcg32` 头注「流为输入非结果」同源）——kernel 零 RNG 状态算术、零整数取模。host 以 `Pcg32::new(SEED, t·4+1)`（RIS 流；`variance_experiment` 每 trial 三流 `stream = t·4+k` 字面，k=1 = RIS；k=0 uniform / k=2 时域链本面不消费）**模拟消费点**产出「已对齐消费序」随机带两条：**候选带** = 每 trial 满长度 16 个 `(next_u32() as usize) % 64` 字面值；**判定带** = 仅在 update 真实消费点（w_sum > 0）产出的 `next_f32()` 值变长序列——**短路点带内无位**（非全量生成后跳选，host 模拟即消费点本体）。交错序还原声明：host 单流内 u32 候选抽取与 f32 WRS 判定按 `estimate_ris` 字面交错消费，拆带保各自子序，device 逐带顺序消费 ⇒ 消费点语义与 host 完全同构。**录制形态（禁第二实现）**：随机带由 bin-local 以 `Pcg32` Copy 快照 + 冻结模块 `update` 本体驱动录制（消费判定事实 = update 后 `r.w_sum > 0`；消费值 = update 前快照重放 `next_f32()`；候选抽取与 w 提升两行字面同源复写）——禁在 bin 内复刻 update/merge 判定逻辑的第二份消费点实现。**f32 精确可表域声明**：候选索引 ∈ [0,63] 整数、`next_f32` 值为 24 位尾数、offset 表 ≤ 320000 < 2²⁴、消费计数 ≤ 16——两带、offset 表与计数输出全 f32 精确承载，kernel 维持全 f32 SSBO 纪律，u64 零下发。**offset 表形态钉死（F1 disposition）**：逐 trial 三元组 `[cand_offset, dec_offset, dec_len]` f32 平铺表（cand_offset = t·16 闭式亦可由表承载——统一走表消除隐式闭式依赖）；**消费计数锚检出力如实声明**：钉死夹具下全灯 phat > 0 ⇒ 首候选起 w_sum > 0 ⇒ 判定带逐 trial 消费恒 16——该锚在本夹具下检出力平凡化（恒等断言仍恒跑防协议漂移），**整数锚真实承重 = 保留样本 y 逐 trial 全等**（判定边界翻转的直接检出面）。**录制自检锚（F2 disposition）**：host 对拍参考值 = 冻结 API `estimate_ris` **直调**产出（录制器只产随机带不产参考值）；前置自检 = 录制循环终态 reservoir 四元组 (y, phat_y, w_sum, m) 与 `estimate_ris` 直调终态**逐 trial 位级相等**——录制骨架与冻结本体漂移即 FAIL 不进对拍。
3. **精度承载定盘（F3 disposition：f64 幻影态删除）**：树内事实 = rurixc device 两条路径对 f64 均为 **RX6026 构造性拒绝**（`vulkan_codegen.rs` 注记，RXS-0203 L1；全部在树 kernel 与 shader spec 零 f64）——「kernel f64 态」在现行语言面**不可达**，激活须语言语义扩展（独立 Full RFC 级，与本 RFC「零新语言语义条款」判档冲突）⇒ **本 RFC 唯一精度承载 = f32**：kernel 内 w/w_sum/W/estimate 以 f32 承载（host 对应量为 f64——host↔device 精度差走标定容差对拍协议，RFC-0043 §1.4 同模）。比较形态 **`u < w/w_sum` 除法比较不可改写**（禁乘法移项 `u·w_sum < w`——零/边界面语义与舍入均不同）；w_sum 恒为顺序累加（禁归约树重排）。**零容差只能是 measured 事实**——标定腿实测 p100=0 方可登记零容差零条目（f32 vs f64 累加链差异使位级不保先验成立，预期走容差带；禁以「理论应位级」手写零容差）。语言面 f64 kernel 扩展承接锚 = 独立 Full RFC 评估窗（§5.8）。
4. **夹具字面（`g21_restir_probe` 逐字同源）**：SEED = 0x0521_A011_2026_0824、N_TRIALS = 20000、M_CANDIDATES = 16、64 灯环形夹具（`fixture_lights`：`a = i/n·TAU`，pos [2.5·cos a, 1.5+0.8·sin(3a), 2.5·sin a]，intensity 0.4+3.6·((i·7+3)%n)/n）、单着色点。probe 的 uniform 对照（k=0）与时域链（k=2 流 / 8 帧 / M-cap 60）**本面不 device 化**——merge/M-cap 语义由 §2 空间臂以 host 形态承载，时域 device 化承接锚 = 生产集成窗（§5.2/§5.5）。
5. **判据面**（程序产禁手写）：
   - ① **device vs host 逐 trial estimate 对拍**：全 20000 trial 逐 trial 绝对差 p100 ≤ 标定容差（标定腿程序产 threshold = measured × 2.0 冻结 k，禁手写，RFC-0043 §1.4 同模；实测 p100=0 → 登记零容差零条目）。**前置整数锚断言**：逐 trial 判定带消费计数 device vs host 模拟全等（本夹具下恒 16 的平凡化事实 §1.2 已声明，恒跑防协议漂移）+ **保留样本 y 全等（真实承重锚）**——desync/翻转即 FAIL 不进容差比较（f32 判定边界翻转致 y 锚失败 = 如实红，容差协议不豁免整数判定面；修复途径 = 判定算术等效承载评估〔语言面 f64 扩展 Full RFC 窗 §5.8〕，另立只追加修订）；
   - ② **无偏 3σ 维持**：device 臂 20000 trial estimate 均值 vs `exact_direct` f64 解析全灯和参考，`dev < 3σ_mean + 1e-9`（σ_mean = sqrt(var/n)，probe 三 σ 检验同式；统计聚合留 host f64 顺序累加 §5.7）。与 ① 的关系显式声明：① 带内 + host 无偏在案（G21 M-a 绿件）⇒ ② 逻辑蕴含，但 ② 独立直接对解析参考复核、不依赖 ① 链路——纵深防御并列，冗余是设计而非疏漏（RFC-0044 §1.2 ③ 同模）；
   - ③ **device 双跑位级一致**：同设备同驱动窗口内固定输入两跑逐 trial 输出缓冲 digest 位级相等；
   - ④ **kernel-bias RED 臂**：params 注入 RED_BIAS = 0.05 输出面（estimate）加性偏置 → 对拍必超容差检出；量化兜底断言 **tol < RED_BIAS × 0.5**（标定容差绝对上界，封死「标定与判定同实现」循环论证，RFC-0043 §1.4 F4 同律；零容差态下该臂退化为「偏置注入 ⇒ p100 = 0.05 ≠ 0 必红」平凡成立仍恒跑）；
   - ⑤ **spirv-val**：kernel 编译产物 SPIR-V 验证通过。
6. **三态协议**：无 Vulkan loader/设备 → device 腿 `SKIP DEV_ENV_DEGRADE`（退 0，非 fake pass，如实登记不冒充；evidence schema `skipped_dev_env` 合法态；`RURIX_REQUIRE_REAL=1` 下 SKIP→硬红由 smoke 脚本层裁决）；host 腿恒跑；判据不符 / RED 臂失效 ⇒ FAIL 退 1。
7. **确定性协议**（`kernels/g18_light_transport_depth.rx` 头注 RXS-0357 L2 同律继承）：禁 atomic、逐 trial 独立（invocation 间零交互）、trial 内 M 候选 WRS 链单线程固定求值序（浮点累加序 = host 字面序）、输出直写、随机性全部来自 host 预生成带、固定输入双跑位级一致。
8. **host 参考臂冻结**：`src/rurix-render/src/gi/restir_reservoir.rs` vs `g27-closed` **0-byte**（git-diff 机核，RFC-0043 F2 / RFC-0044 §1.5 冻结先例同模）；M100 低档面 `gi/multi_light.rs` 及其 `check_restir_trigger`/`restir_serve` fail-closed 登记面同冻（RFC-0038 §2 不变量字面）。device 臂为 bin-local adapter 加性面（`g26_framegen_device`/`g27_hzb_device` 集成路径同模，经 `rurix_rt::vk::run_compute` 派发），不回写 host 模块、不接线任何生产车道（M100 车道集成显式 out-of-scope §5.2）。

## 2. 空间重用加性臂（M-b，bin-local，host 形态）

1. **夹具扩展（bin 内合成，host 模块 0-byte；F6 disposition：参数闭集钉死）**：`fixture_lights(64)` 灯场 + **8×8 着色点网格（N = 8 闭集，非可调基线）**：pos = (−1.75+0.5·i, 0, −1.75+0.5·j)，i,j ∈ 0..8，normal [0,1,0] 全同——网格内嵌灯环半径 2.5 内且全灯高度 ≥ 0.7 ⇒ 逐点 ndotl > 0 全支撑、p̂ 跨点变化非退化（**全支撑构造 = 无偏前提的夹具级保证**：Bitterli Alg.6 之 Z = m 情形，非全支撑 Z 修正显式 out-of-scope §5.10）。全部 bin-local 只消费冻结模块公开 API（**闭集：`fixture_lights`/`ShadePoint`/`PointLight`/`Reservoir`(empty/update/merge/unbiased_weight)/`estimate_ris`/`exact_direct`/`target_phat`/`Pcg32`**——F5 disposition 补列 `target_phat`/`unbiased_weight`）。**统计功效声明（F7 disposition）**：64 点 × 20000 trial 下聚合 3σ 检出限约 0.02σ 量级，对 percent 级结构性偏置留约一个数量级检出裕度（评审独立验证入档）；k=3 流族与 §1/probe 三流 k∈{0,1,2} 残差类构造性不相交 + PCG32 inc = (stream<<1)|1 两两互异 ⇒ 流独立性构造性成立（G21 绿件流域零重叠声明）。**流纪律**：每着色点每 trial 单流 `stream = (t·64 + p)·4 + 3`（p = 行主序点索引 0..64；k=3 残差类与 §1/probe 三流 k∈{0,1,2} 残差类构造性不相交，PCG32 inc = (stream<<1)|1 流两两异）；SEED 同 §1.4；流内消费序 = 先本点 M=16 候选 RIS（`estimate_ris` 字面交错消费）后邻域固定序 merge 判定。
2. **空间合并语义（时域/空间同律 + 受点重评钉死）**：合并输入 = 各邻居**合并前** RIS reservoir 快照闭集（gather 形态；禁 in-place 链式污染——合并输入面不含已合并产物）；邻域 = von Neumann 4-邻接，按 (−1,0)/(+1,0)/(0,−1)/(0,+1) **字面固定序**链式 merge（保浮点序与 RNG 消费序；越界邻居缺席 = 不调用 merge，与 merge 空 other 早退同义零消费）。合并律 = host `merge` 字面同律：空 other 早退不消费、`m_other = other.m.min(m_cap)`（M-cap = 60 probe 字面；基线 m=16 < 60 不触截断，截断活性由冻结面单测 `reservoir_mcap_bounds_confidence` 承载不复测）、等效权 = **p̂_y·W_other·m_other**（merge 头注字面）、`w_sum += w_other`、判定 `w_sum > 0 && next_f32() < w_other/w_sum` 除法比较形不可改写、`m = m_before + m_other`。**受点重评钉死（结构性无偏前提；F5 disposition：零复刻实现路径）**：跨着色点合并时 p̂_y 必须在受点重评——`w_other = target_phat(sp_受点, lights[other.y])·(other.w_sum/(other.phat_y·other.m))·m_other`（other.phat_y ≤ 0 或 other.m = 0 ⇒ w_other = 0）；host merge 的 `other.w_sum·m_other/other.m` 字面捷径**仅在同目标函数（时域同点，p̂_受点 ≡ other.phat_y）下与本律重合**，异点直用即邻点归一化常数混入 ⇒ 结构性偏置（RIS 无偏贡献权恒等式 E[g(y)·W_y] = Σ_x g(x) 只对受点目标 g 成立）。**实现路径 = 受点重评快照变换后直调冻结 merge（禁第二实现）**：构造邻居快照变换 `other' = Reservoir { y: other.y, phat_y: p̂_受点(other.y), w_sum: p̂_受点(other.y)·W_other·other.m, m: other.m }`（W_other = other.unbiased_weight() 冻结 API 直调）——代数恒等：merge 对 other' 的字面等效权 `other'.w_sum·m_other/other'.m = p̂_受点·W_other·m_other` 恰为受点重评律 ⇒ 合并本体仍为冻结 `merge` 直调，bin 内零合并判定复刻（评审报告代数验证闭环在档）；判据 ① 的 3σ 检验即本前提的机器验证面；保留样本换为邻样本时 phat_y 槽位由 merge 语义自然携带受点重评值（other'.phat_y 即受点口径），estimate = `phat_y·unbiased_weight()` 逐字（§1.1 禁化简同律）。
3. **等验证预算口径**：每着色点每 trial 恰 1 保留样本（`variance_experiment` 头注同义）——空间合并零新增候选、零新增保留样本，p̂ 受点重评（≤4 次/点/trial）为无射线着色算术，不计验证预算。no-reuse 对照臂 = 同 trial 同流合并前快照的 estimate（零额外 RNG，成对对照）。
4. **判据面**（程序产禁手写）：
   - ① **无偏 3σ 维持（聚合硬门 + 结构兜底 + 逐点诊断）**：硬门 = 逐 trial 网格均值序列（64 点 estimate 均值/trial）的 20000-trial 均值 vs 64 点 `exact_direct` 均值，`dev < 3σ_mean + 1e-9`（单检验无多重比较膨胀）；结构兜底 = 任一点逐点偏差超 **5σ** 即 FAIL（结构性偏置检出，5σ×64 点族假红 ≈ 3.7e-5 可忽略）；逐点 3σ 诊断表 64 行全量入 evidence 如实登记（3σ×64 族期望假红 ≈ 0.17，故逐点 3σ 为诊断登记面非门面——多重比较口径显式注明）；
   - ② **空间方差再收益 measured 登记**：逐点 var(no-reuse)/var(reuse) 与网格聚合（min/mean/max）如实登记——**不设通过线**（G6 无硬门纪律；RFC-0038 §1.2 方差收益程序产同源；收益/无收益/负收益均如实落 evidence）；
   - ③ **双跑位级**：固定 seed 全网格两跑 estimate 矩阵位级相等（host f64 确定性，`variance_experiment` 双跑位级同律）；
   - ④ **host 0-byte**：§1.8 冻结机核覆盖（空间臂全 bin-local，冻结文件零触碰）。
5. **M100 锚事实登记与过述防线**：M-a + M-b 绿件 ⇒ M100-high 承接锚字面（g25 handover M100-high 行「device 化/空间重用/M100 车道集成窗（RFC-0038 out-of-scope）」）三件中**前两件命中的事实登记**（登记 ≠ 车道集成兑现；第三件「M100 车道集成窗」= 生产 GI 车道消费需求出现，本期不出现 §5.2）。**过述防线**：本 RFC 任何叙述不得引为 M100-high 车道锚整体兑现或低档 MegaLights 生产默认档更替（`multi_light` 0-byte 字面维持）——RFC-0044 §3.2 同模。

## 3. M52/RD-040 workload 重判程序（M-c）

1. **输入面（逐字引证）**：g25 handover M52 行（G28 法定输入）锚 = 「RT pipeline/SBT 宿主车道出现（RD-040 分项 reeval_anchor）」；`G21_P2_DECISIONS.md` §1 M52 行承接锚字面 = 「**重判条件 = RT pipeline/SBT 宿主车道出现（RD-040 分项 RT-PIPELINE-SBT reeval_anchor）；兜底 = 语言层不加 SER 原语维持（字面 0-byte）**」；原判两半在案 = capability 半边 available（`g21_ser_capability_probe_results.json`：`VK_NV_ray_tracing_invocation_reorder`/`VK_EXT_ray_tracing_invocation_reorder`/`rayTracingInvocationReorderReorderingHint` 三 token + capability_verdict=available，RTX 4070 Ti 取证）+ workload 半边未命中（G21.2 M-b：RT pipeline/SBT 车道零实现）。

3. **RD-040 五分项逐锚重判（F9 disposition：manifest 忠实性纪律）**：输入 = `g21_rd040_subitem_registry.json` 五分项闭集（0-byte 只读；「M-c 唯一消费面」字面沿用）。逐项 reeval_anchor 字面树内实测——**逐分项独立 manifest**（每分项 ≥2 条 pattern + 每条 pattern 旁注其对应的锚字面关键词映射，pattern↔锚映射表与命中数同批入 evidence 供评审面复核——manifest 只防空不防歪的缺口以映射表显式化收口）：SMRT「多灯动态场景资产入压测清单 + shadow page 采样车道出现」→ 压测清单盘点（cornell/bistro-interior 闭集现状）+ 采样车道检索；WORLD-RC「世界级持久 GI 需求场景出现（大世界流送 + GI 联动窗）」→ 需求场景/联动窗痕迹检索（RXS-0396 世界缓存已落地面 ≠ 演进需求证据，不混同——RFC-0044 §4.4 同模）；NRD「自研降噪画质差距 measured 检出（G25 终审窗或后续画质门）」→ 树内 measured artifact 检索；OMM「alpha-tested 几何主导场景入压测清单（BistroExterior 植被面 = G24 转换臂窗联动）」→ 压测清单盘点（G10-N6 维持 defer 在案互核）；RT-PIPELINE-SBT「hit/miss 着色阶段语义需求成立（多材质 RT 分派需求证据）+ SER 收益 measured 预估窗」→ 与 §3.2 ② 同批检索互核。预期五项全未命中 → 维持 defer 如实登记；任一命中 → 该分项重判程序启动登记（只登记启动事实与证据路径，分项实现归 §5 各承接锚窗）。

1. **RT pipeline/SBT 实现**（kernel 子语言 hit/miss 着色阶段语义扩展，语言面 Full RFC 级——RD-040 分项 basis 字面）：承接锚 = hit/miss 着色阶段语义需求成立（多材质 RT 分派需求证据，RT-PIPELINE-SBT reeval_anchor 字面）+ §3.2 两半全齐改判窗；本期语言层不加 SER 原语兜底维持。

5. **kernel 性能优化**（超对拍需求面的调度/占用率/共享内存优化）：承接锚 = device 车道进生产集成窗时按 measured 瓶颈立项。

7. **f64 归约树并行化**：统计聚合（mean/var）留 host f64 顺序累加（§1.5 ② 字面）；承接锚 = 聚合面成为 measured 瓶颈（生产集成窗联动）。

10. **非全支撑场景 Z 修正**（F11 补项）：generalized balance heuristic / Z 计数修正——本期夹具全支撑构造回避（§2.1 声明）；承接锚 = 非全支撑资产场景入压测闭集。
11. **ReSTIR GI 域定界与时空联合臂**（F11 补项）：本 RFC 限 DI reservoir（直接光照采样域）；ReSTIR GI（路径重用）与时域+空间联合重用臂承接锚 = 生产 GI 车道消费需求出现（M100 车道集成窗同源）。
