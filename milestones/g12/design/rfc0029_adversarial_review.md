> **评审方法**：评审轮次与起草轮次隔离——独立评审视角重读全文（correctness / 判档边界 / 可实现性三镜头），findings 驱动 v0.2 修法批；zero shared context 声明按单会话先例如实登记（见文末 provenance 偏差登记）。

## 1. findings 与修法 diff（v0.1 → v0.2）

### F1（high）delta 光源 MIS 权重退化路径未定义

**finding**：§4.1 L1 原稿写「权重 = balance heuristic」但未处理 delta 光源（点光）——BSDF 策略对 delta 光源 PDF 为零，balance heuristic 分母 p_nee + p_bsdf 中 p_bsdf=0 时权重计算存在除零/未定义路径；G12.2 实现波若按字面实现，点光场景（bistro 4+ 点光）MIS 权重非确定。
**修法（§4.1 L1 v0.2）**：补「delta 光源（点光）NEE 策略 PDF 按冲激处理——BSDF 策略对 delta 光源概率为零，权重退化 w_nee=1 不产生除零；非 delta 光源（面光/发光面）双策略均可能非零，权重闭式计算」。

### F2（high）RR 截断偏置路径未封

**finding**：§4.2 L1 原稿写「p_kill = clamp(1 − T/τ, 0, p_max)」但未界定 p_max 上界语义——若 p_max=1（或未界定），深路径被确定性杀死引入截断偏置（系统性变暗，与 R-G12-2 能量偏置同族）；N_min 最小反弹保障原稿有但未与 p_max 联动。
**修法（§4.2 L1 v0.2）**：补「p_max < 1 恒成立——任何深度保留非零续行概率，禁截断偏置」并与 N_min ≥ 2 最小反弹保障联动。

### F3（high）自适应终止无 spp 下界 → 早期方差欠估计早停假收敛

**finding**：§4.4 原稿只写「达阈即停采」——像素初始几个样本的方差估计严重欠估计（小样本方差偏差），无下界则大面积像素在第 2~4 样本即「假达阈」早停，收敛报告绿灯但帧质量系统性塌陷（比 R-G12-7 过松冒充收敛更隐蔽的形态）。
**修法（§4.4 v0.2）**：L1 补 spp 下界保障（每像素最小采样数 ≥ N_floor——防早期方差欠估计早停）；L3 误判率标定（对照集 = 自适应帧 vs 全 spp 参照帧同 seed 同场景）；L4 帧型标签闭集 {adaptive, full_reference} 混标即 RED。

### F4（med）「只测量不定档的纪律不适用」与 M120 先例关系未说明

**finding**：§4.3 L1 原稿写「只测量不定档的纪律不适用（本条款冻结选型面）」——与 G9 M120「仅测量不定档（tier_selection.committed==false）」先例的关系未说明，评审担忧构成「不定档纪律」的例外口。
**修法（§4.3 L1 v0.2）**：补同族辨析——M120 不定档 = OIT 档选定程序未解冻（档位承诺面）；采样选型 = 语义面选择非档位承诺，benchmark 裁决证据进 evidence 即闭环，不构成本条款的「不定档」豁免。

### F5（med）「消费历史输出」与「temporal 底座 0-byte」机核边界未定义

**finding**：§4.5 L1 原稿「消费既有 TAA/TSR 历史接口面」与「底座 0-byte」之间缺机核边界——实现波何种改动算「接线」无判据（改 TSR 历史验证参数算不算接线？）。
**修法（§4.5 L4 v0.2）**：显式判据——temporal 底座接线即 RED：任何 TAA/TSR 语义面/代码面改动判 RED；消费 = 只读历史输出接口面（含历史验证参数面 0-byte）。

### F6（med）spp 序列写法像写死数字

**finding**：§4.6 L2 原稿「spp 序列逐段（1/4/16/64/256/1024 段）」——像写死契约数字，违反本 RFC 零写死数字阈值纪律（P-09）。
**修法（§4.6 L2 v0.2）**：改示例形态「如 1/4/16/64/256/1024 段」——实际序列进场景契约 digest（G12.4 波裁决）；容差标定程序产不预写。

### F7（med）降噪条款落点未定

**finding**：§5 原稿把降噪条款直接映射 `spec/global_illumination.md`——降噪含显示管线面（后处理链排序），落点单一映射未裁决。
**修法（§5 v0.2）**：落点改「global_illumination.md 追加条款（或 display_pipeline.md 候选——落点裁决 spec-first 波定，候选文件本体 0-byte）」，沿 G9.4/G10.4 新建/落点先例。

### F8（low）多光源 MIS 光源分布确定性未明确

**finding**：§4.1 L2「联合 PDF = 离散 × 连续」——光源分布（离散 PDF）的构建确定性未明确，与固定 seed 确定性协议的衔接有缝。
**修法（§4.1 L2 v0.2）**：补「光源分布构建确定性（同场景同分布 digest）」。

### F9（low）与 RFC-0028 衔接未提 RXS-0393 同族关系

**finding**：§6.2 原稿只提能量守恒口径继承——生产化判据「正确性锚 0-byte + measured 不劣于基线锚」与 RXS-0393 两款收敛判定的同族关系未登记。
**修法（§6.2 v0.2）**：补「形态沿 RXS-0393 两款收敛判定同族」。

### F10（low）U3 场景集与 G10-N6 联动未登记

**finding**：§8 U3「PT 对标场景集扩场景」——与 G10-N6（BistroExterior FBX2glTF 缺口 defer）联动未登记，存在借 PT 对标静默扩容缺口场景的缝。
**修法（§8 U3 v0.2）**：补「扩容走 M133 只追加修订程序（G10-N6 承接锚字面维持——FBX2glTF 缺口不随 PT 对标静默扩容）」。

## 2. 三镜头复核结论（v0.2 后）

- **correctness 镜头**：F1/F2/F3 三个 high 均为「语义未定义路径 → 实现波非确定/偏置」类，v0.2 已全部闭式化（delta 退化、p_max<1、N_floor 下界）；能量守恒（§4.1 L3）与无偏补偿（§4.2 L2）判据可机核。
- **判档边界镜头**：本 RFC 七子面均属运行时渲染语义面 + 冻结面演进（RXS-0357），Full 判档成立（RFC-0025/0028 先例同族）；SER/材质链/NRD 接入/帧率通过线/绝对画质线五个边界声明（§2.4/§6.4）与承接锚字面逐字一致，无静默扩张。
- **可实现性镜头**：§4 全部语义面均有既有承载（M96 megakernel + host oracle 同构面、TAA/TSR 历史接口面、UE 5.8.1 MRQ 出图面、度量基建面），spec-first 条款路径与 conformance 锚定形态沿 G9.4~G11.5b 先例，无新工程量黑洞；U1~U4 未决问题均登记处置路径不阻语义冻结。
