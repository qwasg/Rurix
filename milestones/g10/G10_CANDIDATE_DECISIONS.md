## 4. 裁决口径说明与汇总

1. **十锚全 defer-to-G11+，零 go**：G10 为对标基线期（出图环境/语料/度量/A/B 四件），十锚重判条件所需的 measured 举证、真实消费方、设备资产、升级评估窗均非 G10 实现面产出——其中 **M99-clipmap / M100-high / M98-l4 三锚登记「G10 触发评估」**（G10 A/B 对比与大世界压测语料恰是其 measured 举证的法定产出通道，举证落地后经只追加程序重判 go 并由 G11 画质修复期承接）；**M52 锚定 G12**（路径追踪生产化期 = 高分歧 RT workload 真实集成面）；**M114-strand 锚定 G14**（性能对标期 = M120 精确档裁决数据天然产出窗）；SAFE-GPU/M127/M118-hdr-cal/M125-adopt3/M61 五锚维持原方向顺延。
2. **承接锚字面 0-byte**：十锚承接锚逐字引自 `milestones/g9/G9_P2_DECISIONS.md` §3（2026-08-14），本表只登记「G10 不消费、窗口顺延」，不改写原文；「G10+ 重评窗」涵盖 G11+，顺延不构成违约。
3. **open RD 七条全维持 open**：RD-034 blocked 维持；RD-039/040/041 维持 open 且各含部分分项 G10 触发评估登记（M44-p4 超显存语料 / M99-clipmap+M100-high 举证通道 + NRD 同族 / FSR-DirectSR 同族评估）；RD-042/043 观察维持；RD-044 maintain_no_go 维持。条目级 status 与 id/title/reason/backfill_condition 四字段 0-byte，history 只追加。
4. **新增候选五行**：go 4 行（G10-N1 出图环境路径 / G10-N2 压测语料许可 / G10-N3 图像度量基建 / G10-N4 首轮 A/B 与差距清单）+ defer-to-G11+ 1 行（G10-N5 DLSS/Streamline 方向登记，锚定 G13）。波次归属为建议值，待 G10_PLAN 冻结。
