1. 做了什么
---------------------------------------------------------------------------------
1.1 mark 段真上 device(设计 §2.1 帧循环第一行 / §2.3 第一核)
  * fixture 标记源从「host 预知 page id 的 vsm.mark_slot(l,x,y)」换成
    「主相机深度 → 反投影 → 选级 → 出窗回退 → 页位图」:
      - 深度网格 64×64(`MARK_DIM`),1.0 = 天空(page_mark 剔除);
      - 反投影矩阵行主序 [[2,0,0,2],[0,-2,0,2],[0,0,-64,0],[0,0,0,1]]
        ⇒ world = (0.0625·px+0.03125, 0.0625·py+0.03125, −64·d),w≡1;
      - 深度三档 D_L0=0.5/64(dc≈7.5 ⇒ 0 级)、D_L1=13/64(dc≈20 ⇒ 1 级)、
        D_L2=33/64(dc≈40 ⇒ 2 级);离级/页边界均 ≥3 / ≥0.03 世界单位,
        host f32 与 device f32 的 log2/ceil/floor 不在边界分叉;
      - F0–F12 四块 ⇒ L0(0,0)/L0(1,0)/L1(0,0)/L2(0,0)(= 旧 core_slots,故
        F0–F12 的事件/digest 逐字不变);F13–F15 压力块 ⇒ L0(2,0)…(9,0) 8 页。
  * `Vsm` 加性拆分:`page_mark_bits`(纯函数,device 核的 host 镜像)+
    `apply_mark_bitmap`(host 消费位图:帧标记戳 + 帧龄归零)+
    `marked_slots_from_bitmap`(位图 → 分类/alloc 的输入序);`page_mark` 改为
    两者的组合 ⇒ 既有调用方(uc06/uc08/单测)语义 0-byte。
  * device 段每帧 dispatch `vsm_page_mark_project`(4096 线程)+ readback
    4096 字位图,与 host 镜像逐位(word)+ 逐槽(slot 列表)对拍;`levels*512`
    之后的字必须全零(越界写检测)。
  * local spot 的 mark 仍走 host 白盒槽:`vsm_page_mark_project` 的输入布局是
    方向光 clipmap 栈(逐级 lparams + 选级/回退环),不覆盖 spot 单级透视页表
    (设计 §2.3 第一核只列方向光 mark)⇒ 显式记账,不计入 device 判据。

1.2 validation_errors 去字面量
  * 删 `let validation_errors = 0u32;`。
  * `rurix_rt::render_exec` 加进程级 `VALIDATION_ERROR_TOTAL`(两个 messenger
    回调共同累加)+ `VALIDATION_MESSENGER_INSTALLED`,经
    `validation_error_total()` / `validation_messenger_installed()` 暴露。
  * smoke 的 `validation_zero` = errors==0 **且** messenger 装上
    (否则 0 分不清「真跑零 ERROR」与「layer 没装、没人报」)。
